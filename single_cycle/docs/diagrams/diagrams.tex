  {\large RV32I + Zmmul + custom-0 INT8 instructions (\sv{DOT4.S8}, \sv{CLIP.S8}) \quad$\cdot$\quad RTL in \sv{rtl/}}
\end{center}

\noindent The core executes one instruction per clock cycle. It is built from five
\emph{stage modules} (\sv{if\_stage}, \sv{id\_stage}, \sv{ex\_stage}, \sv{mem\_stage},
\sv{wb\_stage}); \sv{riscv\_core} only wires them together. In iteration 2 the pipeline
registers IF/ID, ID/EX, EX/MEM and MEM/WB go on exactly the wires that cross the stage
borders in Figure~\ref{fig:dp}, and the stage modules stay as they are.
Every name in the figures is the exact SystemVerilog port or signal name.


\medskip
\noindent\textbf{How to read the figures.} Thick border: holds state. Thin border: combinational.
Green trapezium: multiplexer (the numbers are the select values). Solid navy: data.
Dashed orange: control. A small square on a stage border is a module port; \texttt{/32} is a bus width;
a dot joins wires. In Figure~\ref{fig:dp}, rounded flags such as \fbox{\sv{rs2\_data}} are net labels
(the same wire as the signal of that name), and each select is drawn as a named dashed stub.

\section*{Control unit (\sv{rtl/control.sv}, PDF Table 9.2)}
\noindent\textbf{Extensions.} Two units sit beside the ALU in \sv{ex\_stage}: \sv{mul\_unit} (Zmmul:
\sv{mul}, \sv{mulh}, \sv{mulhsu}, \sv{mulhu}; no divide) and \sv{nn\_unit} (custom-0: \sv{DOT4.S8},
a signed 4\,$\times$\,int8 dot product accumulated into \sv{rd}, and \sv{CLIP.S8}, a clamp to $[-128, 127]$).
The control signal \sv{ex\_sel} picks which unit's result becomes \sv{ex\_result}, so every later stage
(and, in the pipeline, every forwarding path) still sees one result per instruction.
\sv{DOT4.S8} reads \sv{rd} as a third source through register-file port 3 (\sv{rs3\_data}).

\smallskip
\noindent A dash means ``does not matter''; the code then drives the safe default (0 / \sv{ALU\_ADD} / \sv{IMM\_I} / \sv{WB\_ALU}).
\sv{reg\_write} and \sv{mem\_write} are never don't-cares. \sv{funct3} and the full \sv{funct7} (\sv{instr[31:25]}) refine the
operation for \sv{OP\_REG} / \sv{OP\_IMM}; \sv{instr[30]} selects \sv{sub} \emph{only} in \sv{OP\_REG}, and \sv{sra}/\sv{srai} in both.

\noindent Extra outputs: \sv{system} = 1 for \sv{OP\_SYSTEM} (the testbench stops on \sv{ebreak}).
\sv{illegal} = 1 for an unknown opcode, and for every undefined funct3/funct7 combination of
\sv{OP\_REG} (defined: funct7 \sv{0000000}; \sv{0100000} with \sv{sub}/\sv{sra} only; \sv{0000001} with funct3 \sv{0xx},
so \sv{div}/\sv{divu}/\sv{rem}/\sv{remu} are illegal), of the \sv{OP\_IMM} shifts, and of custom-0
(defined: \sv{DOT4.S8} and \sv{CLIP.S8} with rs2 field \sv{00000}). An illegal word writes nothing.
\sv{rs3\_read} is not used by the single-cycle core; the pipeline's hazard check needs it.
