\noindent The single-cycle core's stage modules with the IF/ID, ID/EX, EX/MEM and MEM/WB registers
on the wires between them. \sv{id\_stage}, \sv{ex\_stage} and \sv{wb\_stage} are reused unchanged;
\sv{if\_stage} and \sv{mem\_stage} change because both memories now read synchronously, as FPGA block
RAM does. The figures use the single-cycle diagrams' conventions: thick border = holds state, thin =
combinational, green trapezium = multiplexer, solid navy = data, dashed orange = control. Every name is
the exact SystemVerilog name.

\medskip
\fig{fig_pipeline}{0.97}{The pipelined datapath (\sv{riscv\_core.sv}). Forwarding muxes sit in front of
\sv{ex\_stage}; \sv{rf\_bypass} after the register file; the data memory straddles EX/MEM because its address
register is the address half of EX/MEM. \sv{pc\_redirect} from EX is the flush.}
